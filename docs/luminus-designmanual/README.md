# Luminus designboard

`index.html` är en fristående sida (öppna i webbläsaren) med Luminusprofilens visuella identitet: nuläge och en moderniserad version 2 med logotyp, färg, typografi, Luminuscirkeln, bildspråk, Instagram-mallar och dokumentmallar.

- Typsnitt: Fraunces och DM Sans (Google Fonts, SIL Open Font License).
- `assets/luminus-logo-nuvarande.png` är logotypen som den ser ut i artikeln "Luminus profile 20 characters" (2024), utdragen som referens.
- Hexvärden för nuläget är uppmätta ur PDF- och bildfiler. Version 2 är ett designförslag.
